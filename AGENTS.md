Sift is an ai agent built to manage ones newsletters using a dedicated email. It helps with generating summaries, selecting the ones based on your interest, and managing all of them in one place instead of bloating your personal inbox.

The project has 3 major directories:

- core: implementation of the core logic.
- cli: UI integrationg for CLI based usage.
- web: UI integrationg for GUI based usage.

Tech stack :

- agentmail
- websockets
